PyCharm plugin · Python developer tools

Navigate resources like Python symbols.

Resource Navigator turns recognized Python file paths, project resources, and web URLs into navigable IDE targets. Ctrl+Click to open resources, resolve supported static expressions, and catch missing files with configurable inspections.

Get the latest release Explore the source

Built for resource-heavy Python projects

Ctrl+Click navigation

Open recognized local files, directories, and HTTP/HTTPS URLs directly from Python code, with Go to Declaration support.

Static expression resolution

Resolve supported adjacent literals, constant f-strings, constant references, concatenation, and pathlib constructors.

Missing-resource inspections

Identify unresolved file references with configurable Conservative, Balanced, and Aggressive detection policies.

Developer conveniences

Quick Documentation, Open Resource, Reveal in File Manager, and Copy Full Path actions.

Broad file support

PDFs, images, Office documents, Markdown, HTML, notebooks, structured data, and more.

Python-aware behavior

Preserve normal PyCharm navigation for Python symbols while making supported resource literals navigable.

Python paths become navigation targets

Examples of supported resource expressions, subject to static resolution and project configuration:

from pathlib import Path

manual = "docs/manual.pdf"
image = Path("assets") / "diagram.svg"
website = "https://www.python.org/"

Use Ctrl+Click or Go to Declaration on recognized resource references to navigate to their targets.

Install Resource Navigator

  1. Download the latest resource-navigator-*.zip from GitHub Releases.
  2. In PyCharm, open Settings → Plugins, select the gear menu, and choose Install Plugin from Disk.
  3. Select the ZIP and restart PyCharm when prompted.

Supported IDE baseline: PyCharm 2025.2 (build 252) or later. See the README for development and configuration details.

Stay up to date

Resource Navigator publishes an IntelliJ-compatible custom plugin repository feed. Add the URL below under Settings → Plugins → Manage Plugin Repositories and select that repository as Resource Navigator's Updates from source.

https://jschelert1.github.io/resource-navigator/updatePlugins.xml

The update feed points to release ZIP assets hosted on GitHub.
