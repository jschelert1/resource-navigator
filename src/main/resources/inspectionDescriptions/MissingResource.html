Reports local resource references that cannot be resolved.

This inspection detects missing local resources referenced by supported Python string expressions. Resource Navigator evaluates supported compile-time string constructs, including ordinary string literals, adjacent string literals, constant f-string interpolation, constant references, string concatenation, and supported pathlib constructors.

Supported pathlib constructors include Path(...), PurePath(...), PureWindowsPath(...), and PurePosixPath(...).

Absolute filesystem paths are resolved directly. Relative paths can be resolved against the current source-file directory and/or the project root, depending on the Resource Navigator settings.

Filesystem glob patterns and unresolved or unsupported dynamic expressions are not reported as missing resources. HTTP and HTTPS URLs are also intentionally excluded from missing-resource inspection.

Resolution behavior and recognized resource extensions can be configured under Settings | Tools | Resource Navigator.
